# فایل‌های صوتی قلعه‌ی ذهن

این پوشه برای فایل‌های صوتی واقعی (mp3) است.

## فایل‌های مورد نیاز

- `horn.mp3` — شیپور فتح شهر
- `drum.mp3` — درام سقوط کاخ
- `defeat.mp3` — درام عمیق پایان سقوط
- `urge-hit.mp3` — پالس کوتاه ضربه
- `resist.mp3` — نُت مثبت دفع
- `sos-alarm.mp3` — سه بوق تیز
- `breath-in.mp3` — نفس عمیق (دم)
- `breath-out.mp3` — بازدم
- `rise.mp3` — آکورد برخاستن
- `ambient-loop.mp3` — پس‌زمینه ملایم
- `city-freed-fanfare.mp3` — فانفار فتح شهر (نسخه‌ی بلندتر)

## نکته مهم

اگر فایل‌های mp3 در این پوشه نباشند، برنامه به‌صورت خودکار از **oscillator داخلی** (Web Audio API) استفاده می‌کند. بنابراین نیازی به فایل‌های واقعی برای اجرای برنامه نیست.

برای تجربه‌ی بهتر، فایل‌های واقعی را اضافه کنید.

## فرمت

- فرمت: MP3
- بیت‌ریت: 128-192 kbps
- مدت: کوتاه (۱-۵ ثانیه برای اکثر صداها)
- `ambient-loop.mp3`: می‌تواند طولانی‌تر باشد (۳۰-۶۰ ثانیه)
